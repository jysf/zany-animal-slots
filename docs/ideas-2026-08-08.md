# Ideas — 2026-08-08

Brainstorm from a lifetime-report analysis session. Nothing here is scoped,
decided, or committed to — a raw list to pick from later, not a roadmap.

## In-app, on the animal-slots product itself

- **Seeded challenge mode.** DEC-002 made the RNG seedable/injected purely
  for testability. A daily-seed mode (everyone plays identical spins today,
  compares outcomes) turns that test infrastructure into a Wordle-style
  feature for free — no engine changes needed.
- **Player-facing machine remix.** DEC-015 proved a machine is just config,
  six times over (Arctic, Desert, Ocean, Farm, Diner, retuned default). The
  next step past "add a 7th hand-authored machine" is a bounded slider UI
  (variance, hit-rate, jackpot rarity) that lets a player build one,
  validated by the same metrics simulator (SPEC-044) used internally to
  balance the existing six.
- **Embrace the "cheap" sound on purpose.** The audio-spike (2026-07-15)
  diagnoses the synth audio as bare/dry and recommends warming it up. A
  different, cheaper answer: a "retro cabinet" toggle that leans into the
  bleepy oscillator tone as an aesthetic choice instead of fixing it.
- **Meta easter egg.** A hidden machine themed on the build process itself
  (symbols = spec/decision/token glyphs, jackpot = "shipped") — a wink at
  the project's own paper trail, low stakes, high novelty.
- **Ghost replay / compare.** SPEC-078's trophy-replay tech already
  reconstructs a specific spin. Point it at "replay your own biggest win
  from last session" for a lightweight flex loop without real multiplayer.

## Process ideas, portable to other projects

- **Delegation-drift audit.** The real finding from the 2026-08-08 lifetime
  analysis: the architect/implementer split (Opus designs, Sonnet builds)
  quietly collapsed after 2026-07-24 and nobody caught it until a manual
  spec-by-spec read of `cost.sessions[].model`. A script that walks any
  spec-driven repo's cost fields and flags N consecutive specs with
  architect == implementer would have caught this in days, not weeks.
  Portable to any repo using this template's cost-tracking convention.
- **SPEC-094-style deferral.** Reserve the ID, write the deferral reason
  and a concrete revisit trigger in the doc where the work would have
  lived, instead of silently dropping it. Portable to any backlog —
  spec-driven or not.
